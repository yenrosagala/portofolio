Papua Province · 29 Regencies

PDRB Growth
Spatial Impact Analysis

Comparing existing vs. future route network effects on regional economic growth using Spatial Autoregressive (SAR) models, network multiplier decomposition, and Bézier curve visualization across 29 kabupaten/kota in Papua.

View ResultsLinkedIn
01 — Context

Research Overview

This study investigates whether expanding Papua's transportation route network generates measurable spatial spillover effects on regional PDRB (Gross Regional Domestic Product) growth. An intercept-only SAR model is estimated under two network configurations: the existing route structure and a future (prospected) network incorporating new hub connections.

Study Area

29 kabupaten/kota in Papua Province (KODE_PROV 91), Indonesia — one of the most infrastructure-challenged regions in Southeast Asia.

Model

Intercept-only Spatial Autoregressive (SAR) model with row-standardised weight matrices comparing existing and future route networks.

Key Finding

The future network shows positive spatial dependence (ρ = 0.343), whereas the existing network shows none (ρ = −0.022). 5 previously disconnected regencies gain network access.

02 — Methodology

Analytical Framework

A spatial econometric pipeline: shapefile ingestion → weight matrix construction → OLS baseline → Moran's I test → SAR estimation → LeSage impact decomposition → network multiplier analysis.

A

Data & Shapefile

Administrative boundaries (Kab_Kota.shp) filtered for KODE_PROV == 91. Route adjacency matrices read from Excel — Existing sheet and Future sheet. Hub dependence matrix merged via element-wise max to produce the future network.

B

OLS Baseline & Moran's I

Intercept-only OLS regression on Miskin (food insecurity). Moran's I test on residuals using the future weight matrix confirms significant positive spatial autocorrelation (I = 0.284, z = 2.40, p = 0.008).

C

SAR Model (lagsarlm)

Spatial lag model estimated under both existing and future weight matrices. Future network yields positive ρ = 0.343 (p = 0.087), indicating emerging spatial dependence when new routes are added.

D

Network Multiplier Decomposition

Using S = (I − ρW)⁻¹, the total multiplier matrix is computed for both networks (ρ held constant). Row sums give per-regency multipliers; their difference quantifies the policy gain of network expansion.
