Building a Custom Accept-Rejection Sampler for the MSN Burr Distribution

TL;DR: Standard optimization algorithms fail when estimating parameters for highly complex, skewed distributions. I built a custom Markov Chain Accept-Rejection Sampler from scratch in R to accurately estimate parameters for the MSN Burr distribution.

The Problem

In statistical modeling, real-world data (like insurance claims or machine failure rates) rarely follows a perfect normal distribution. The MSN Burr distribution is excellent for this because it handles heavy tails and extreme skewness.

However, it has a major flaw: its likelihood function is a mathematical nightmare. It's highly multimodal, meaning standard out-of-the-box functions in R (like optim() or maxLik) frequently crash or give completely wrong answers by getting stuck in "local dips" rather than finding the true bottom of the curve.

The Solution

Instead of relying on pre-built packages, I wrote a custom Markov Chain Monte Carlo (MCMC) algorithm utilizing an Accept-Rejection Sampling technique.

The mathematical "trick" I leveraged was using the standard Burr distribution as the proposal engine. Because of how the Skew-Normal transformation works, the complex math cancels out perfectly, resulting in an incredibly fast and elegant acceptance ratio that doesn't require calculating massive matrix inversions at every step.

The Code

Here is the core of the custom random number generator I built. Notice how clean the acceptance step (w) becomes once the baseline densities cancel out:

rmsnburr <- function(n, c, k, lambda, alpha = 0, beta = 1) {
  samples <- numeric(n)
  accepted <- 0
  
  while(accepted < n) {
    # 1. Propose from baseline Burr distribution
    y <- rburr(1, c, k, alpha, beta)
    
    # 2. Calculate elegant acceptance probability (M=2, densities cancel out)
    F_y <- pburr(y, c, k, alpha, beta)
    F_y <- pmax(pmin(F_y, 1 - 1e-10), 1e-10) # Boundary safety
    w <- pnorm(lambda * qnorm(F_y)) 
    
    # 3. Accept or Reject
    if (runif(1) <= w) {
      accepted <- accepted + 1
      samples[accepted] <- y
    }
  }
  return(samples)
}

Visualizing the Results

To prove the algorithm works, I used ggplot2 to generate samples from the distribution across varying levels of skewness (λ). As you can see, the algorithm perfectly captures everything from extreme left-skew to extreme right-skew.

Why This Matters

By building this from the ground up rather than using a black-box package, I ensured the model would not fail on edge-case datasets. The MC-ARS method proved to be highly robust, consistently converging on true parameter values with low Mean Squared Error (MSE), even with small sample sizes.
